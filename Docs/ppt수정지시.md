### 🔴 NEW-2 (16장 **앞**에 삽입) — 가장 중요한 추가 슬라이드

> **제목**: 아키텍처 결정이 3주 뒤에 값을 한 순간
> **부제**: Core에 UnityEngine이 없어서, 에디터를 켜지 않고 보드 60,000개를 검증할 수 있었다.

**왜 이 슬라이드가 필요한가**: 4장에서 `noEngineReferences: true` 를 설명하지만, 지금 초안에서는
*"테스트가 3초에 돈다"* 로만 끝납니다. **좋은 설계를 했다는 주장**과
**그 설계가 실제로 값을 했다는 증거**는 다릅니다. 이 슬라이드가 그 증거입니다.

- **무엇을 했나**
  - `.csproj` 에 `<Compile Include=".../Core/**/*.cs" />` **한 줄** → Unity 없이 콘솔 앱으로 컴파일
  - 무작위 보드 **60,000개**를 생성해 중력 불변식을 전수 검사
  - 같은 방식으로 EditMode 테스트도 `dotnet test` 로 **0.3초** 완주 (Unity Test Runner는 2.54초)
- **무엇을 찾았나**
  - 코드 주석은 *"모든 칸이 항상 채워진다"* 고 **주장**했고, 테스트 166개도 **통과 중이었다**
  - → **손으로 고른 보드에서만 참**이었다. 퍼즈가 반례를 찾아냈다
  - **이번에 나온 버그 3개를 전부 퍼즈가 잡았고, 손으로 짠 테스트 166개는 하나도 못 잡았다**
- **핵심 문장 (크게)**
  > 테스트가 있다는 사실이 오히려 안심시켰다. **불변식은 주장이지 보장이 아니다.**
- **주의(부록/노트용)**: NUnit은 반드시 **3.x** — 4는 `Assert.AreEqual` 등 classic assert를 없애서
  Unity(NUnit 3) 코드가 그대로 안 붙는다

## ③ 17장 분할 — 항목 12개는 한 장에 못 읽는다

현재 17장에 버그 12개가 한 장에 있습니다. **3장으로 나누세요.**

### 17-A — 대표 사례 3건 (각 3~4줄로 깊게)

1. **게이지가 안 줄어든다 — 3번 재발**
   `Image.type`이 `Filled`가 아니면 `fillAmount`가 **아무 일도 안 한다.** UI 스프라이트를 꽂을 때
   Unity가 9슬라이스를 감지해 `Sliced`로 되돌려 놓고 있었다. 게다가 `sprite`가 null이면 Image는
   **언제나 칸을 꽉 채운다.**
   → `Awake`에서 게이지 3종을 강제 설정.
   **교훈: 세 번 재발한 버그는 주의가 아니라 코드로 막는다.**

2. **벽 밑에 빈 칸 — 테스트가 통과하는데 불변식이 거짓이었다**
   대각선 슬라이드는 **한 칸짜리 이동**이라 출처가 정확히 대각선 위여야 하는데, 그 자리가
   벽·보드 밖·빈 구멍이면 **도달 가능한 타일이 물리적으로 없다.** (가장 흔한 경우는
   **부서진 벽이 남긴 자리**)
   → 구멍을 리필 입구까지 **걸어 올라가게** 해서 옆 타일로 메운다 (실측 **99.08%**).
   **교훈: 불변식은 주장이지 보장이 아니다. 반례를 찾으러 가야 한다.**

3. **보스 타일이 보드를 도배한다 — 확률의 단위**
   확률이 **리필 타일 하나하나에** 굴려지고 있었다. 한 웨이브에 10칸이면 주사위를 10번 던진다.
   **"5% 확률"이 실제로는 `1 − 0.95¹⁰ = 40%`였다.**
   → 동시 상한 + 웨이브 누적 카운터.
   **교훈: 확률은 "무엇 당(per)"인지 같이 적는다.**

### 17-B — 나머지 9건 (표로 요약, 각 1줄)

| 증상 | 진짜 원인 | 조치 |
|---|---|---|

| 폰트 사전 생성이 글씨를 날림 | 386자를 1024×1024 한 장에 구우니 **두 장째로 넘침** | 2048로 확대 + **넘침 에러 로그** |
| 타일이 옆 열을 가로지름 | 모델이 압축한 낙하 기록을 뷰가 **직선 보간** | 꺾인 경로 + 전체 길이를 하나의 자로 |
| 확인창이 항상 같은 문구 | `OnEnable`이 코드가 먼저 쓴 값을 **덮어씀** | 값이 아니라 **키**를 갈아 끼운다 |
| 인살 뒤 버튼이 「처형」인 채 | **상태 변화만 구독** — 변화 없이 의미가 달라지는 경우를 놓침 | 지금 상태에서 다시 그린다 |
| 그리드 에디터가 지나가기만 해도 칠해짐 | `evt.type`은 그리드 밖 MouseUp을 못 받는다 | **`evt.rawType`** + 드래그 중복 방지 |
