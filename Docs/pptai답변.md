데이터 흐름과 경계 규칙
경계를 넘는 방법을 3가지로 정해서 모든 배선이 한 가지 패턴을 따른다.

•
경계를 넘는 규칙 3가지
밸런스 수치는 전부 ScriptableObject: 코드에 상수로 박힌 밸런스가 0이다.
Unity 타입은 Func<>로 감싼다: AnimationCurve → Func<float, float> → Core가 커브를 "값을 돌려주는 함수"로만 알므로 Unity를 몰라도 된다.

•
효과
스테이지를 재배치하거나 추가해도 코드를 한 줄도 안 고친다. 난이도 표를 손으로 적었다면 스테이지를 늘릴 때 표 갱신을 잊어 새 판만 조용히 물렁해진다.
